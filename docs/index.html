Install

一键安装

一条命令完成安装与升级,无需 Python / pip。Windows 用 PowerShell,其余平台用 curl。

macOS / Linux

终端执行,自动识别平台并下载最新版。

curl -fsSL https://orzmc.github.io/OrzPythonMC/install.sh | sh

重复执行即覆盖升级;--version vX.Y.Z 可固定版本(绕过 GitHub API 限流)。

Windows(PowerShell)

PowerShell 5.1+,执行策略不影响此方式。

irm https://orzmc.github.io/OrzPythonMC/install.ps1 | iex

安装到 %LOCALAPPDATA%\Programs\orzmc 并登记用户 PATH。

其它安装方式

PyPI

需 Python 3.10+。

pip install orzmc-app

升级:pip install -U orzmc-app · uv 用户:uv tool install orzmc-app

独立二进制

免 Python / Java,解压即用。自动识别你的平台,也可手动选择。

Uninstall

卸载

推荐使用内置统一卸载:一条命令删除二进制、还原安装器对 PATH 的修改。游戏数据(默认 ~/minecraft)默认保留。

内置统一卸载(推荐)

任意安装方式都适用,自动清理安装记录与 PATH 修改。

orzmc self-uninstall --yes

删除二进制、还原安装器登记的 PATH、清理空目录。--remove-root 连游戏数据一起删;--yes 免确认(脚本化调用)。与 orzmc remove(移除某个 Minecraft 版本)不同,这里卸载的是工具本身。

按安装方式手动卸载(备用)

PyPI 方式

卸载 Python 包。

pip uninstall orzmc-app

游戏数据(默认 ~/minecraft)不会随包删除,需要时手动 rm -rf ~/minecraft(Windows 为 rd /s %USERPROFILE%\minecraft)。

独立二进制

删除下载的 orzmc 可执行文件。

rm -f ~/.local/bin/orzmc

示例为 ~/.local/bin,实际以你放置的目录为准;Windows 删除对应的 orzmc.exe。游戏数据同样不会自动删除。

Quickstart

快速开始

安装后直接命令行使用;版本缺失时自动下载补齐,无需单独的 install 步骤。

# 安装(Unix 一条命令;Windows 用 irm https://orzmc.github.io/OrzPythonMC/install.ps1 | iex)
curl -fsSL https://orzmc.github.io/OrzPythonMC/install.sh | sh

# 启动最新版(26.2)原版客户端;-v 缺省时自动用 Mojang 最新 release
orzmc client -v 26.2

# 以 Fabric 启动客户端
orzmc client -v 26.2 -t fabric

# 部署并启动 Paper 服务端(自动接受 EULA,无窗口模式)
orzmc server -v 26.2 -t paper --yes --nogui

项目特性与价值

OrzMC 把启动器的重复工作收进一个包:依赖管理、Java 托管、多版本并存、服务端部署,都是开箱即用。

多版本并存

客户端 / 服务端一版本一目录,互不干扰;一台机器轻松切换任意版本与类型。

☕

Java 运行时沙盒

按版本自动下载所需 JRE 并托管到应用目录,不依赖系统 Java,版本要求自动判定。

⌨️

交互式版本选择器

全屏键盘导航:方向键选择、输入即过滤、正式版 / 测试版一键切换,回车即启动。

🖥️

服务端部署一键化

自动接受 EULA、写入配置;支持 vanilla / Paper / Fabric / Forge,--nogui 无窗口启动、stop 或 Ctrl-C 优雅关闭。

六平台全覆盖

macOS / Linux / Windows × x86_64 / arm64,为每个平台构建独立二进制,发布即用。
